# My Automotive Project

A multi-page automotive engineering portfolio website built to document my learning journey through technical study, workshop exposure, and analytical automotive case studies.

The project focuses on understanding vehicles beyond performance figures and exterior design by exploring the engineering systems, design tradeoffs, and practical repair processes behind modern automobiles.

---

## Project Overview

This website includes:

- A structured introduction about my automotive learning journey
- Practical workshop exposure and observations
- Automotive fundamentals and engineering systems
- A real-world automotive case study
- A functional contact page integrated with Firebase

---

## Sections Included

### Home

A landing page introducing the purpose and direction of the project.

### About

Covers:

- My interest in automotive engineering
- Workshop exposure
- Technical observations
- Current learning focus
- Future goals

### Fundamentals

Explores core automotive systems including:

- Engine systems
- Suspension
- Braking systems
- Engineering tradeoffs and design thinking

### Case Study

A structured real-world workshop-related automotive case study including:

- Vehicle overview
- Problem analysis
- Diagnosis process
- Engineering observations
- Technical learnings

### Contact

A Firebase-integrated contact form allowing visitors to send messages directly through the website.
